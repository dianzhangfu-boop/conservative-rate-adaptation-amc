# Figures — provenance

All figures in this directory are generated by `../make_figures.py` from the
archived results; no figure is produced from a fresh simulation.

| File | Source | What it shows |
|---|---|---|
| `fig1_pipeline.png` | schematic, no data | Processing chain, causal separation and offline evaluation path |
| `fig2_tradeoff.png` | `artefact/test/metrics_per_run.csv` | Mean F_aggr vs G for A, B-per and C across the 24 main cells |
| `fig3_h3_noise.png` | `artefact/analysis/hypotheses.json` | D(1) and D(3) with 95 % CIs; the pre-registered H3 legs |
| `fig4_h4_stress.png` | `artefact/analysis/h4_contrasts.csv` | Stress-cell ΔG with 95 % CIs and the 0.05 threshold |

`checksums.json` records the SHA-256 of each PNG. Regenerate with:

```
cd phase3
python -I make_figures.py
```

The script reads only archived metrics and writes only to `figures/`; it does
not import or modify the frozen controller or any experimental artefact.
